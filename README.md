# Dingus Eggs

A productivity tracker that turns goals into Dingus Eggs — earn them by completing tasks, hatch them to win pets, weapons, vehicles, and more. Build streaks, level up, equip your loot, and battle Sword Steve in the Colosseum.

## Run locally

Open `index.html` in any modern browser. No build step required.

## Tech

Single-file HTML/CSS/JS app with vanilla JavaScript. All state persists to `localStorage`.

## Features

- Pixel-art chibi avatar with deep customization
- Goals with categories, priorities, subgoals, daily streaks
- Egg system (small / big / huge) with weighted drop rates by rarity
- 130+ hatchable items: pets, accessories, weapons, vehicles, backgrounds, themed frames
- The Hatchery — walkable scene with The Hatchery, Egg Marketplace, Trophy Room, Garage, and Colosseum
- Colosseum 1v1 weapon-clash mini-game vs Sword Steve (practice mode)
- XP, levels, achievements
- Super Duper Simple Mode — distraction-free legal-pad view for focused work
- Marketplace egg trades + duplicate item trade-ins
- Sound effects, confetti, animations
- Export/import save data
